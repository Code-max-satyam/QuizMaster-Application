# 🧠 QuizMaster Application

An interactive and visually engaging **Quiz Application** built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**.  
It allows users to sign up, log in, take quizzes on various technologies, and view their performance results with analytics.

---

## 🚀 Features

- 🔐 **User Authentication** (Register & Login using JWT)
- 📊 **Personalized Quiz Results** stored per user
- 🧩 **Filter Results** by technology and level
- 💻 **Responsive UI** with modern animations and styling
- 🗄️ **Secure Backend** using Express & MongoDB Atlas
- 🌈 **Dynamic Performance Badges** (Excellent, Good, Average, Needs Work)

## 🛠️ Tech Stack

### 🌐 Frontend
- React.js
- React Router DOM
- Lucide React Icons
- Tailwind CSS / Custom CSS
- React Toastify (for alerts)

### ⚙️ Backend
- Node.js
- Express.js
- JWT Authentication
- bcryptjs (for password hashing)
- Mongoose (MongoDB ORM)
- dotenv (for environment variables)
- CORS enabled for frontend-backend communication

### 🗃️ Database
- MongoDB Atlas (Cloud Database)
